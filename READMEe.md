#  Student Data Cleaning Project

##  Overview
This is a beginner-friendly data cleaning project using Python and Pandas.  
The project focuses on cleaning student marks data and preparing it for analysis.

---

##  Dataset
The dataset contains student marks in:
- Math
- Science
- English

It also includes some issues like:
- Missing values
- Duplicate rows

---

##  Steps Performed
- Loaded dataset using Pandas
- Removed duplicate records
- Filled missing values using average (mean)
- Converted data types to integers
- Created a new column: **Total Marks**
- Created a new column: **Grade**

---

##  Tools Used
- Python
- Pandas
